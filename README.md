# 図形の動き × デネットの三つのスタンス

Heider & Simmel 風の動画3本を学生が各自の端末で見て解釈を書き、その解釈を OpenAI API で「物理／設計／志向／判定不能」に下書き分類し、先生が結果サイトで手直しする授業ワークです。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 学生用の回答ページ（学籍番号 → 動画3本をランダム順で視聴・記述） |
| `results.html` | 結果サイト（動画ごとの分布と回答一覧。学籍番号は表示しない。先生モードで分類と修正） |
| `scenes.js` | 動画3本のアニメーションと再生エンジン |
| `config.js` | GAS の URL などの設定（ここだけ書き換える） |
| `api.js` / `common.css` | 通信処理と共通スタイル |
| `gas/Code.gs` | スプレッドシート側の Apps Script（GitHub には置かなくてよい） |

`config.js` の `GAS_URL` が空のときはテストモードです。回答ページは送信せずに進み、結果サイトはサンプルデータを表示します。

## 動画

| ID | 名前 | 長さ | 内容（先生用） |
|---|---|---|---|
| A | 輪 | 74秒 | 輪の中の円、やってくる四角、侵入する三角。追跡と逃走 |
| B | 坂 | 64秒 | 坂を登れない円、下から押し上げる四角、上から押し戻す三角。最後に円は四角のそばへ行く |
| C | 広場 | 64秒 | 特定のモチーフなし。模倣、接近と後退、割り込みと周回、離脱とためらいながらの帰還、並んでの移動、追従と退場 |

## セットアップ

### 1. スプレッドシートと Apps Script

1. Google スプレッドシートを新規作成する。
2. 「拡張機能」→「Apps Script」を開き、`Code.gs` の中身を `gas/Code.gs` の内容に置き換えて保存する。
3. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に次を追加する。
   - `OPENAI_API_KEY`：OpenAI の API キー
   - `TEACHER_PASSWORD`：結果サイトの先生モード用パスワード
   - `OPENAI_MODEL`（任意）：使うモデル名。省略すると `gpt-4.1-mini`
4. エディタ上部の関数選択で `setup` を選んで実行し、権限を承認する。シート `responses` が作られる。
5. `testClassify` を実行すると、API キーとプロンプトの動作をログで確認できる（シートには書き込まない）。

### 2. ウェブアプリとしてデプロイ

1. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
2. 次のユーザーとして実行：**自分**。アクセスできるユーザー：**全員**。
3. 表示された URL（`https://script.google.com/macros/s/…/exec`）をコピーする。

コードを直したときは「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」で更新すると、URL が変わらない。

### 3. GitHub Pages

1. `config.js` の `GAS_URL` に上の URL を貼る。
2. `gas/` 以外のファイルをリポジトリに置き、Settings → Pages で公開する。
3. 学生には `…/index.html`、授業の後半で `…/results.html` を案内する。

### 4. 本番前の確認

1. `index.html` で学籍番号 `test` などで最後まで回答し、シートに3行入ることを確かめる。
2. `results.html` の「先生用」でパスワードを入れ、「未分類をAIで分類する」を押す。
3. 確認が終わったらシートからテスト行を消す。

## 授業での流れ（例）

1. 学生が `index.html` で3本を見て記述する（10〜15分）。
2. 先生が `results.html` の先生モードで「未分類をAIで分類する」を押す。60人×3本なら数分で終わる。
3. スクリーンに結果サイトを映し、分布と回答を見ながら、AIの判定に違和感のあるものを先生（または学生と議論しながら）直す。
4. 学生にも `results.html` を開いてもらい、動画ごとの違いや、どこで志向スタンスが立ち上がったかを議論する。

## 仕様メモ

- **シートの列**：`id, timestamp, studentId, sessionId, videoId, position, order, text, plays, watchedSec, userAgent, autoLabel, autoReason, autoModel, autoAt, teacherLabel, teacherAt`
  - `position` はその学生にとって何本目だったか、`order` は再生順（例 `BCA`）
  - `plays` は最初から再生した回数、`watchedSec` は実際に再生していた秒数
- **再送信**：同じ学籍番号・同じ動画の回答は上書きされ、ラベルは未分類に戻る。
- **表示されるラベル**：先生のラベルがあればそれを、なければAIのラベルを表示する。先生のラベルはAIの再分類で上書きされない。
- **OpenAI に送るもの**：記述テキストのみ。学籍番号は送らない。
- **結果サイトに出すもの**：記述テキストとラベルのみ。学籍番号は返さない。
- **分類をやり直す**：Apps Script で `clearAutoLabels` を実行してから、結果サイトで再度分類する。
- **プロンプトの調整**：`Code.gs` 冒頭の `PROMPT` を編集する。境界例（「追いかける」の一語だけの記述など）の扱いはここで決めている。
- 学生の端末では、回答途中の内容と進み具合がブラウザに保存されるので、ページを再読み込みしても続きから再開できる。
